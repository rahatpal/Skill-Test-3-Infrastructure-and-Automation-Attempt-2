# Deployment screenshots

The 12 PNG files document Terraform initialization, the full plan, successful creation of two resources, the running EC2 instance, official Ubuntu 20.04 AMI, existing default VPC, HTTP/SSH rules, the working Nginx page and destruction of two resources.

The screenshots show an Ubuntu 20.04 deployment on `t3.micro` in Mumbai. See the [main README](../README.md) for the configuration and evidence.

The main README embeds all images, with supporting details in expandable sections. No separate SSH check or post-destroy console images were captured. Original screenshots retain AWS account identifiers and the console account name; no credential values or private keys are visible.
